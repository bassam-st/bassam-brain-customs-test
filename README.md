# bassam-brain-customs-test

تطبيق تجريبي مستقل يجمع بين:

- وضع الجمارك: يبحث داخل ملف الأصناف الجمركية ويحسِب الجمارك من السعر والفئة المحفوظة فقط.
- الوضع العام: يستخدم Groq / Anthropic عند توفر مفاتيح API، ويمكنه استخدام Google Search عبر Serper عند توفر المفتاح.

## مهم
هذا المشروع لا يلمس تطبيق Bassam Brain الأصلي ولا تطبيق الجمارك الأصلي. هو نسخة تجريبية مستقلة.

## التشغيل محليًا

```bash
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 7860
```

ثم افتح:

```text
http://localhost:7860
```

## التشغيل في Hugging Face Spaces

1. أنشئ Space جديد باسم `bassam-brain-customs-test`.
2. اختر SDK: Docker أو Gradio/Static لا يهم، لكن الأفضل استخدام Python/FastAPI عبر `app.py`.
3. ارفع ملفات هذا المشروع.
4. أضف المتغيرات السرية إن رغبت:
   - `GROQ_API_KEY`
   - `ANTHROPIC_API_KEY`
   - `SERPER_API_KEY`
5. شغّل الـ Space.

## طريقة الحساب

```text
الجمارك = usdPrice × الكمية المحسوبة × 750 × categoryFactor
```

## إضافة أصناف جديدة بسهولة

من داخل التطبيق:

1. افتح تبويب **إدارة الأصناف**.
2. أدخل اسم الصنف، البند، السعر، الوحدة، الفئة، والأسماء البديلة.
3. اضغط **إضافة الصنف**.
4. الصنف سيُحفظ في متصفحك مؤقتًا ويظهر مباشرة في البحث والحساب.
5. اضغط **تصدير نسخة محدثة JSON** لتنزيل ملف جديد يحتوي الأصناف الأصلية + الأصناف الجديدة.

لجعل الإضافة عامة لكل المستخدمين:

1. خذ الملف المصدّر من التطبيق.
2. استبدل به الملف:
   `data/customs-backup-2026-06-09.json`
3. أعد نشر التطبيق.

## ملاحظة مهمة عن التحديثات

هذه النسخة تستخدم ملف JSON ثابت. إذا أضفت صنفًا في تطبيق الجمارك الأصلي فلن يظهر هنا تلقائيًا إلا إذا صدّرت نسخة JSON جديدة ورفعتها لهذا المشروع. الربط التلقائي لاحقًا يحتاج Firestore Read-only API.
